- Object 클래스가 최상위 부모인 이유

1. 공통 기능 제공
객체의 정보 제공, 다른 객체와의 비교, 객체의 클래스 내용을 파악하는 것은 모든 객체에게 필요한 내용이다. 이를 각 개발자들이 따로 구현하게 된다면,
같은 기능에 대한 각각의 다른 메서드가 생기기에 java에서는 이를 직접 Object 클래스를 통해서 제공한다.

2. 다형성의 기본 구현
Object 클래스는 모든 클래스의 부모 클래스이므로 모든 객체를 담을 수 있다. 즉 모든 객체를 참조할 수 있다.
이를 통해 모든 자바 객체는 Object 타입으로 처리될 수 있고, 다양한 타입의 객체를 통합 처리할 수 있게 한다.
-> 이에 대한 구체적인 내용을 object.poly 패키지에서 확인해보자.
